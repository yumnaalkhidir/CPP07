# CPP07

42 School C++ Module 07 — introduction to C++ templates (functions and a templated Array class).

## Concepts covered
- Generic function templates (swap/min/max-style)
- A templated Array class
- Template specialization basics

## Exercises
ex00 ex01 ex02 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
